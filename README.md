# code

Allgemeines Repository von Tekin Bayazit für neue Projekte mit Claude Code.

Jede App bekommt einen eigenen Ordner (z. B. `notizen/`).

## Apps

- `steuer/` – **Steuer-Kompass**: Interview-Assistent zur Schätzung der Einkommensteuer (2024/2025) mit Live-Berechnung der Erstattung. Deckt Lohn, Vermietung mit Flächenanteil, Kapitalerträge mit Verlustverrechnung, private Verkäufe (Krypto), Kinder und Fünftelregelung ab. Reine Browser-App ohne Server: `steuer/index.html` öffnen. Tests: `node --test steuer/tax.test.js`.
